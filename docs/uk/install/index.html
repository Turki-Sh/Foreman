Foreman / Встановити

Встановіть Foreman.

одна папка з файлами Markdown. Немає компіляції чи виконання, тому він працює всюди, коли агент читає інструкції.

Claude Code

Виконайте обидва рядки в цьому порядку. Вони додадуть посібник і чотири інструменти як слеш-команди.

/plugin marketplace add Turki-Sh/Foreman
/plugin install foreman@alshuaibi

Якщо ваш інтерфейс Claude Code не підтримує /pluginвиконайте ці команди у своїй оболонці, а потім почніть новий сеанс.

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi

оновіть або видаліть

Оновлення з вашої оболонки:

claude plugin marketplace update alshuaibi
claude plugin update foreman@alshuaibi
/plugin uninstall foreman@alshuaibi

Використовуйте це зі своєю командою.

необов’язковий для проектів, де Foreman є частиною спільного робочого процесу.

з каталогу проекту запустіть:

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi --scope project

Це записує налаштування Foreman у .claude/settings.json:

{
  "enabledPlugins": {
    "foreman@alshuaibi": true
  }
}

зберегти існуючі налаштування та інші записи плагіна. Перегляньте різницю, а потім зафіксуйте цей файл, щоб співавтори отримали конфігурацію. Кожен співавтор усе одно виконує дві команди на своєму комп’ютері. Закріплення налаштувань не завантажує плагін для них.

для особистого користування збережіть стандартну інсталяцію області користувача. Спільний доступ необов’язковий і працює також у приватних сховищах. Зберігайте облікові дані та особисті налаштування подалі від спільного файлу.

Області встановлення · Спільні налаштування

програми Claude

Завантажити foreman.skill і завантажте його в налаштуваннях навичок. Усередині є режими та всі чотири інструменти. Попросіть звичайними словами, наприклад: «Перевір мій сайт за допомогою Punch list».

Інші агенти

Cursor, Windsurf, Codex, Copilot, Gemini CLI, Cline або будь-що, що читає навички чи правила. Скопіюйте одну папку.

git clone https://github.com/Turki-Sh/Foreman.git
cp -r Foreman/plugins/foreman/skills/foreman ~/.agents/skills/
ІнструментКуди помістити папку
Каталог універсальних навичок~/.agents/skills/foreman/
Cursor~/.cursor/rules/, або .cursor/rules/ в проекті
Codex~/.codex/skills/foreman/, або посилання на нього з AGENTS.md
GitHub Copilot.github/copilot-instructions.mdабо вкажіть на SKILL.md
Windsurf.windsurfrulesабо каталог правил робочої області
Gemini CLIGEMINI.mdабо каталог розширень
Cline, Continue, RooПоле спеціальних інструкцій або правил

Шляхи змінюються разом з інструментами. Головне правило: розмістіть SKILL.md там, де агент читає постійні інструкції, а папки references/, toolbelt/ і assets/ тримайте поруч. AGENTS.md має останню таблицю.

Чат без підтримки навичок

Вставити SKILL.md у чат і попросіть провести вас за цим посібником. Кроки, режими та перевірки працюють з одного файлу. Референси додають подробиці.

Перевірте, чи завантажено

Питання

Чи працює щось на моїй машині? Ні. Foreman містить інструкції Markdown і шаблони для заповнення. У ньому немає скриптів, хуків, MCP-серверів або мережевих запитів; перевірки CI забороняють їх додавання. Агент, як і раніше, використовує власні інструменти з вашого дозволу.

Чи потрібен йому Інтернет? Ні. Survey і Board працюють краще, коли ваш агент може переглядати веб-сторінки. Агент коротко повідомляє вам, коли перегляд недоступний.

З якими моделями він працює? Будь-яка достатньо спроможна модель, яку запускає ваш агент. Записані сесії на цьому сайті використовували Claude Sonnet.

Скільки це коштує? це безкоштовно, за ліцензією MIT.
