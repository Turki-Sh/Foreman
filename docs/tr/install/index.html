Foreman / Yükle

Foreman’ı yükleyin.

Markdown dosyalarından oluşan bir klasör. Derleme veya yürütme yoktur, dolayısıyla bir aracının talimatları okuduğu her yerde çalışır.

Claude Code

İki satırı bu sırayla çalıştırın. Kılavuzu ve dört aracı eğik çizgi komutları olarak ekler.

/plugin marketplace add Turki-Sh/Foreman
/plugin install foreman@alshuaibi

Claude Code arayüzünüz şu komutu desteklemiyorsa: /pluginbu komutları terminalde çalıştırın, ardından yeni bir oturum başlatın.

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi

Güncelleyin veya kaldırın

Kabuğunuzdan güncelleme:

claude plugin marketplace update alshuaibi
claude plugin update foreman@alshuaibi
/plugin uninstall foreman@alshuaibi

Ekibinizle birlikte kullanın.

Foreman'nin paylaşılan iş akışının parçası olduğu projeler için isteğe bağlıdır.

Proje dizininden şunu çalıştırın:

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi --scope project

Foreman yapılandırması şu dosyaya kaydedilir .claude/settings.json:

{
  "enabledPlugins": {
    "foreman@alshuaibi": true
  }
}

Mevcut ayarları ve diğer eklenti girişlerini koruyun. Farkı inceleyin, ardından ortak çalışanların yapılandırmayı alması için bu dosyayı kaydedin. Her ortak çalışan yine de iki komutu kendi makinesinde bir kez çalıştırır. Ayarların kabul edilmesi eklentiyi onlar için indirmez.

Kişisel kullanım için varsayılan kullanıcı kapsamı kurulumunu koruyun. Paylaşım isteğe bağlıdır ve özel depolarda da çalışır. Kimlik bilgilerini ve kişisel geçersiz kılmaları paylaşılan dosyanın dışında tutun.

Kurulum kapsamları · Paylaşılan ayarlar

Claude uygulamaları

İndir foreman.skill dosyasını beceri ayarlarından yükleyin. Modlar ve dört araç da içindedir. Örneğin “sitemi Punch list ile denetle” diyerek aracı isteyin.

Diğer tüm ajanlar

Cursor, Windsurf, Codex, Copilot, Gemini CLI, Cline veya becerileri veya kuralları okuyan herhangi bir şey. Bir klasörü kopyalayın.

git clone https://github.com/Turki-Sh/Foreman.git
cp -r Foreman/plugins/foreman/skills/foreman ~/.agents/skills/
AletKlasörün konumu
Evrensel beceriler dizini~/.agents/skills/foreman/
Cursor~/.cursor/rules/, veya .cursor/rules/ projede
Codex~/.codex/skills/foreman/, veya buradan referans alın AGENTS.md
GitHub Copilot.github/copilot-instructions.md, veya ona doğrultun SKILL.md
Windsurf.windsurfrules, veya çalışma alanı kuralları dizini
Gemini CLIGEMINI.md, veya uzantılar dizini
Cline, Continue, RooÖzel talimatlar veya kurallar alanı

Araçlar değiştikçe yollar da değişebilir. Temel kural: şu dosyayı yerleştirin: SKILL.md Aracınızın kalıcı talimatları okuduğu konumu kullanın. Şu klasörleri de references/, toolbelt/ ve assets/ aynı konumda tutun. AGENTS.md en son tabloya sahiptir.

Beceri desteği olmayan bir sohbet

Şu dosyayı SKILL.md sohbete yapıştırıp “bu kılavuzla beni yönlendir” deyin. Adımlar, modlar ve onay noktaları bu tek dosyayla çalışır. Referans dosyaları ayrıntı sağlar.

Sorular

Makinemde herhangi bir şey çalıştırıyor mu? Hayır. Foreman, Markdown talimatları ve doldurulabilir şablonlardan oluşur. Betik, hook, MCP sunucusu veya ağ çağrısı içermez; CI kontrolleri bunların eklenmesini engeller. Ajanınız kendi araçlarını her zamanki gibi izninizle kullanır.

İnternete ihtiyacı var mı? Hayır. Ajanınız web’de gezinebildiğinde Survey ve Board daha iyi çalışır. Gezinme kullanılamıyorsa ajan bunu kısaca belirtir.

Hangi modellerle çalışır? Ajanınızın çalıştırdığı yeterli yeteneğe sahip herhangi bir modelle çalışır. Bu sitedeki kayıtlı oturumlarda Claude Sonnet kullanıldı.

Fiyatı ne kadar? MIT lisansı altında ücretsizdir.
