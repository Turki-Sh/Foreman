Foreman / Install

Installige Foreman.

Üks kaust markdown. Midagi ei kompileerita ja midagi ei tööta, nii et see installitakse kõikjal, kus agent faile loeb.

Claude Code

Mõlemad read, selles järjekorras. See lisab mänguraamatu ja selle neli tööriista kaldkriipsu käskudena.

/plugin marketplace add Turki-Sh/Foreman
/plugin install foreman@alshuaibi

Kui teie Claude Code pind ei toeta /plugin, käivitage need käsud oma kestas ja alustage seejärel uut seanssi.

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi

Värskenda või eemalda

Värskendus teie kestast:

claude plugin marketplace update alshuaibi
claude plugin update foreman@alshuaibi
/plugin uninstall foreman@alshuaibi

Kasutage seda oma meeskonnaga.

Valikuline projektide jaoks, kus Foreman on osa jagatud töövoost.

Käivitage projektikataloogist:

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi --scope project

See salvestab Foreman tolli .claude/settings.json:

{
  "enabledPlugins": {
    "foreman@alshuaibi": true
  }
}

Säilitage olemasolevad seaded ja muud pistikprogrammi kirjed. Vaadake diff üle ja seejärel kinnitage see fail, et kaastöötajad saaksid konfiguratsiooni kätte. Iga kaastöötaja käitab kahte käsku oma masinas üks kord. Seadete kinnitamine ei laadi nende jaoks mõeldud pistikprogrammi alla.

Isiklikuks kasutamiseks säilitage kasutaja ulatuse vaikeinstallimine. Jagamine on valikuline ja töötab ka privaatsetes hoidlates. Hoidke mandaadid ja isiklikud alistamised jagatud failist eemal.

Claude'i rakendused

Laadi alla foreman.skill ja laadige see üles oskuste seadetesse. Režiimid ja neli tööriista on selle sees. Küsige tööriista lihtsate sõnadega, näiteks "käivita Punch list minu saidil".

Kõik teised agendid

Cursor, Windsurf, Codex, Copilot, Gemini CLI, Cline või midagi, mis loeb oskusi või reegleid. Kopeerige üks kaust.

git clone https://github.com/Turki-Sh/Foreman.git
cp -r Foreman/plugins/foreman/skills/foreman ~/.agents/skills/
TööriistKuhu kaust läheb
Universaalne oskuste kataloog~/.agents/skills/foreman/
Cursor~/.cursor/rules/või .cursor/rules/ projektis
Codex~/.codex/skills/foreman/või viidake sellele AGENTS.md
GitHub Copilot.github/copilot-instructions.mdvõi suunake see sellele SKILL.md
Windsurf.windsurfrulesvõi tööruumi reeglite kataloog
Gemini CLIGEMINI.mdvõi laienduste kataloog
Cline, Continue, RooKohandatud juhiste või reeglite väli

Teed liiguvad tööriistade muutudes. Reegel, mis töötab alati: pane SKILL.md , kus teie tööriist loeb kehtivaid juhiseid, ja jätke see alles references/, toolbelt/ ja assets/ selle kõrval. AGENTS.md sisaldab uusimat tabelit.

Vestlus ilma oskusteta

Kleebi SKILL.md vestlusesse ja öelge "run this on me". Sammud, režiimid ja väravad töötavad kõik ühest failist. Viited ainult süvendavad neid.

Kontrollige, kas see on laaditud

Ütle aidake mul oma portfelli koostada. Esimene vastus on see kaart, siis ei midagi. Kui see hakkab kirjutama HTML, siis seda ei laaditud.

Küsimused

Kas see töötab minu masinas midagi? Nr Foreman on markdown ja täitemallid. See ei tarni skripte, konkse, MCP servereid ega võrgukõnesid ning selle CI ebaõnnestub, kui see ilmub. Teie agent kasutab teie loal oma tööriistu, nagu alati.

Kas see vajab Internetti? Ei. Survey režiim ja Board muutuvad paremaks, kui teie agent saab sirvida, ja öelge see ühe reaga, kui see ei õnnestu.

Milliste mudelitega see töötab? Kõik võimalikud mudelid, mida teie agent käitab. Sellel saidil salvestatud jooksud kasutasid Claude Sonnet.

Mis see maksab? Mitte midagi. MIT litsentsitud.
