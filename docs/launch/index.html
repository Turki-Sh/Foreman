How it works.

  1. It reads before it asks. A CNAME file, vercel.json, netlify.toml or a Pages workflow tells it most of what it needs. Then one message for the rest: where it is hosted, whether a domain is bought, and whether that domain carries email.

  2. It fills what is missing before launch. Title, description, canonical, the Open Graph card with an absolute image URL, structured data, a 404 that returns a real 404, robots.txt and a sitemap with true dates.

  3. It ships one step per message. Push, connect a host, point DNS, remove the parking records, wait for the certificate. Before any DNS save, it asks for a screenshot of the record panel and reads it with you.

  4. It proves it. HTTPS in a private window, the 404 status, the share card in a real scraper.

  5. It gets the site found. Search Console and Bing Webmaster Tools, IndexNow where the host supports it, and links from everywhere your name already is.

What stays yours.

Anything that needs your login or your card. It cannot sign in to your registrar, your host or your bank, so it never offers to, and if a coding agent tells you it deployed the site, Foreman checks, because it did not.
