Foreman / 安装

安装 Foreman。

一个文件夹，里面都是 Markdown。无需编译或运行，智能体能读取指令就能使用。

Claude Code

依次执行这两行命令，将指南和四个工具添加为斜杠命令。

/plugin marketplace add Turki-Sh/Foreman
/plugin install foreman@alshuaibi

如果你的 Claude Code 界面不支持 /plugin，请在终端中运行以下命令，然后开启新会话。

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi

更新或删除

从 shell 更新：

claude plugin marketplace update alshuaibi
claude plugin update foreman@alshuaibi
/plugin uninstall foreman@alshuaibi

与您的团队一起使用它。

可选，适用于 Foreman 属于共享工作流程的项目。

从项目目录中，运行：

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi --scope project

这会将 Foreman 的配置记录到 .claude/settings.json:

{
  "enabledPlugins": {
    "foreman@alshuaibi": true
  }
}

保留现有设置和其他插件条目。查看差异，然后提交此文件，以便协作者收到配置。每个协作者仍然在他们的机器上运行这两个命令一次。提交设置不会为其下载插件。

对于个人使用，请保留默认的用户范围安装。共享是可选的，并且也可以在私有存储库中使用。将凭据和个人覆盖保留在共享文件之外。

安装范围 · 共享设置

Claude 应用程序

下载 foreman.skill 并在技能设置中上传。模式和四个工具都在里面。用简单的话索要一个工具，例如“在我的网站上运行 punch list”。

其他智能体

Cursor、Windsurf、Codex、Copilot、Gemini CLI、Cline 或任何读取技能或规则的内容。复制一个文件夹。

git clone https://github.com/Turki-Sh/Foreman.git
cp -r Foreman/plugins/foreman/skills/foreman ~/.agents/skills/
工具文件夹位置
通用技能目录~/.agents/skills/foreman/
Cursor~/.cursor/rules/或者 .cursor/rules/ 在项目中
Codex~/.codex/skills/foreman/，或引用自 AGENTS.md
GitHub Copilot.github/copilot-instructions.md，或将其指向 SKILL.md
Windsurf.windsurfrules，或工作区规则目录
Gemini CLIGEMINI.md，或扩展目录
Cline, Continue, Roo自定义指令或规则字段

工具更新可能改变文件路径。基本原则是：把 SKILL.md 放在智能体读取常驻指令的位置，并将 references/, toolbelt/ 和 assets/ 保存在同一位置。 AGENTS.md 有最新的表。

没有技能支持的聊天

将 SKILL.md 粘贴到对话中，然后说“用这份指南带我完成”。这一个文件就能提供步骤、模式和审批检查点。参考文件用于补充细节。

问题

它在我的机器上运行任何东西吗？ 不会。Foreman 只包含 Markdown 指令和可填写的模板。没有脚本、钩子、MCP 服务器或网络调用；CI 检查会拒绝添加这些内容。智能体仍像往常一样，在你许可下使用自己的工具。

需要网络吗？ 不需要。智能体能够浏览网页时，Survey 和 Board 的效果会更好；无法浏览时，智能体会简短说明。

支持哪些模型？ 智能体支持的、能力足够的模型都可以。本网站录制的会话使用了 Claude Sonnet。

费用是多少？ 它是免费的，遵循 MIT 许可证。
