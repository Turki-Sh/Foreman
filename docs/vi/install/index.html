Cài đặt Foreman.

Một thư mục chứa tệp Markdown. Không cần biên dịch hay thực thi nên nó hoạt động ở bất cứ nơi nào tác nhân đọc hướng dẫn.

Claude Code

Chạy cả hai dòng theo đúng thứ tự này để thêm hướng dẫn và bốn công cụ dưới dạng lệnh gạch chéo.

/plugin marketplace add Turki-Sh/Foreman
/plugin install foreman@alshuaibi

Nếu giao diện Claude Code của bạn không hỗ trợ /plugin, chạy các lệnh này trong shell của bạn, sau đó bắt đầu một phiên mới.

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi

Cập nhật hoặc xóa

Cập nhật từ shell của bạn:

claude plugin marketplace update alshuaibi
claude plugin update foreman@alshuaibi
/plugin uninstall foreman@alshuaibi

Sử dụng nó với đội của bạn.

Tùy chọn, đối với các dự án trong đó Foreman là một phần của quy trình làm việc chung.

Từ thư mục dự án, chạy:

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi --scope project

Điều này ghi lại Foreman trong .claude/settings.json:

{
  "enabledPlugins": {
    "foreman@alshuaibi": true
  }
}

Giữ các cài đặt hiện có và các mục plugin khác. Xem lại sự khác biệt, sau đó cam kết tệp này để cộng tác viên nhận được cấu hình. Mỗi cộng tác viên vẫn chạy hai lệnh một lần trên máy của họ. Cài đặt cam kết không tải xuống plugin cho chúng.

Đối với mục đích sử dụng cá nhân, hãy giữ cài đặt phạm vi người dùng mặc định. Chia sẻ là tùy chọn và cũng hoạt động trong kho riêng tư. Giữ thông tin đăng nhập và thông tin ghi đè cá nhân ra khỏi tệp được chia sẻ.

Phạm vi lắp đặt · Cài đặt chia sẻ

Ứng dụng Claude

Tải xuống foreman.skill và tải nó lên trong cài đặt kỹ năng. Các chế độ và bốn công cụ đều ở bên trong nó. Yêu cầu một công cụ bằng những từ đơn giản, chẳng hạn như "chạy punch list trên trang web của tôi".

Các tác nhân khác

Cursor, Windsurf, Codex, Copilot, Gemini CLI, Cline hoặc bất cứ thứ gì đọc kỹ năng hoặc quy tắc. Sao chép một thư mục.

git clone https://github.com/Turki-Sh/Foreman.git
cp -r Foreman/plugins/foreman/skills/foreman ~/.agents/skills/
Dụng cụVị trí đặt thư mục
Thư mục kỹ năng phổ quát~/.agents/skills/foreman/
Cursor~/.cursor/rules/, hoặc .cursor/rules/ trong dự án
Codex~/.codex/skills/foreman/, hoặc tham chiếu nó từ AGENTS.md
GitHub Copilot.github/copilot-instructions.md, hoặc trỏ vào SKILL.md
Windsurf.windsurfrules, hoặc thư mục quy tắc không gian làm việc
Gemini CLIGEMINI.md, hoặc thư mục tiện ích mở rộng
Cline, Continue, RooTrường hướng dẫn hoặc quy tắc tùy chỉnh

Đường dẫn có thể thay đổi khi công cụ thay đổi. Nguyên tắc là đặt SKILL.md ở nơi tác nhân đọc hướng dẫn thường trực, đồng thời giữ references/, toolbelt/ và assets/ cạnh tệp đó. AGENTS.md có bảng mới nhất.

Cuộc trò chuyện không hỗ trợ kỹ năng

Dán SKILL.md vào cuộc trò chuyện và nói “hướng dẫn tôi làm theo tài liệu này”. Các bước, chế độ và điểm duyệt đều hoạt động từ một tệp. Tài liệu tham khảo bổ sung chi tiết.

Kiểm tra xem nó đã tải chưa

Câu hỏi

Nó có chạy được gì trên máy của tôi không? Không. Foreman gồm hướng dẫn Markdown và mẫu để điền. Không có tập lệnh, hook, máy chủ MCP hay lời gọi mạng; kiểm tra CI sẽ thất bại nếu chúng xuất hiện. Tác nhân vẫn dùng công cụ riêng với sự cho phép của bạn như bình thường.

Có cần internet không? Không. Survey và Board hiệu quả hơn khi tác nhân có thể duyệt web. Tác nhân sẽ báo ngắn gọn nếu không có khả năng duyệt web.

Dùng được với những mô hình nào? Bất kỳ mô hình đủ năng lực nào mà tác nhân của bạn sử dụng. Các phiên được ghi lại trên website này dùng Claude Sonnet.

Giá bao nhiêu? Nó miễn phí, theo giấy phép MIT.
