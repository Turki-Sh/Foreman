Foreman / 설치

Foreman을 설치하세요.

Markdown 파일 폴더 1개. 컴파일이나 실행이 없으므로 에이전트가 지침을 읽을 때마다 작동합니다.

Claude Code

두 줄을 이 순서대로 실행하세요. 가이드와 네 가지 도구가 슬래시 명령어로 추가됩니다.

/plugin marketplace add Turki-Sh/Foreman
/plugin install foreman@alshuaibi

Claude Code에서 다음 명령을 지원하지 않는 경우: /plugin터미널에서 아래 명령을 실행한 뒤 새 세션을 시작하세요.

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi

업데이트 또는 제거

셸에서 업데이트:

claude plugin marketplace update alshuaibi
claude plugin update foreman@alshuaibi
/plugin uninstall foreman@alshuaibi

팀과 함께 사용하세요.

Foreman가 공유 워크플로의 일부인 프로젝트의 경우 선택 사항입니다.

프로젝트 디렉터리에서 다음을 실행합니다.

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi --scope project

Foreman 설정이 기록되는 파일은 .claude/settings.json:

{
  "enabledPlugins": {
    "foreman@alshuaibi": true
  }
}

기존 설정 및 기타 플러그인 항목을 유지합니다. 차이점을 검토한 후 공동작업자가 구성을 받을 수 있도록 이 파일을 커밋하세요. 각 협력자는 여전히 자신의 컴퓨터에서 두 명령을 한 번 실행합니다. 설정을 커밋해도 해당 플러그인이 다운로드되지 않습니다.

개인용으로는 기본 사용자 범위 설치를 유지하세요. 공유는 선택 사항이며 개인 저장소에서도 작동합니다. 자격 증명과 개인 재정의를 공유 파일에 보관하지 마세요.

설치 범위 · 공유 설정

Claude 앱

다운로드 foreman.skill 스킬 설정에 업로드하세요. 그 안에는 모드와 4가지 도구가 있습니다. "내 사이트에서 punch list를 실행해 보세요"와 같은 평범한 말로 도구를 요청하세요.

그 밖의 에이전트

Cursor, Windsurf, Codex, Copilot, Gemini CLI, Cline 또는 기술이나 규칙을 읽는 모든 것. 폴더 하나를 복사합니다.

git clone https://github.com/Turki-Sh/Foreman.git
cp -r Foreman/plugins/foreman/skills/foreman ~/.agents/skills/
도구폴더를 둘 위치
범용 기술 디렉토리~/.agents/skills/foreman/
Cursor~/.cursor/rules/, 또는 .cursor/rules/ 프로젝트에서
Codex~/.codex/skills/foreman/또는 다음에서 참조하세요. AGENTS.md
GitHub Copilot.github/copilot-instructions.md, 또는 다음을 가리킵니다. SKILL.md
Windsurf.windsurfrules또는 작업공간 규칙 디렉토리
Gemini CLIGEMINI.md또는 확장 디렉토리
Cline, Continue, Roo사용자 정의 지침 또는 규칙 필드

도구가 바뀌면 경로도 달라질 수 있습니다. 기본 원칙은 SKILL.md 파일을 에이전트가 상시 지침을 읽는 위치에 두고, references/, toolbelt/ 및 assets/ 폴더도 같은 위치에 보관하는 것입니다. AGENTS.md 최신 테이블이 있습니다.

스킬 지원이 없는 채팅

다음 파일 SKILL.md 를 대화에 붙여 넣고 “이 가이드로 진행해 줘”라고 말하세요. 단계, 모드, 승인 확인은 이 파일 하나로 작동합니다. 참고 파일은 세부 내용을 보완합니다.

질문

내 컴퓨터에서 실행되는 것이 있나요? 아니요. Foreman은 Markdown 지침과 작성용 템플릿으로 구성됩니다. 스크립트, 훅, MCP 서버, 네트워크 호출이 없으며 CI 검사는 이런 항목이 추가되면 실패합니다. 에이전트는 평소처럼 사용자의 허락을 받아 자신의 도구를 사용합니다.

인터넷이 필요합니까? 아니요. 에이전트가 웹을 탐색할 수 있으면 Survey와 Board가 더 효과적으로 작동합니다. 탐색이 불가능하면 에이전트가 짧게 알려 줍니다.

어떤 모델과 호환되나요? 에이전트가 실행하는 충분한 성능의 모델과 함께 사용할 수 있습니다. 이 사이트의 녹화된 세션에서는 Claude Sonnet을 사용했습니다.

비용은 얼마인가요? MIT 라이선스에 따라 무료입니다.
