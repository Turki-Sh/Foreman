Foreman / Install

Install Foreman.

One folder of markdown. Nothing compiles and nothing runs, so it installs anywhere an agent reads files.

Claude Code

Both lines, in this order. This adds the playbook and its four tools as slash commands.

/plugin marketplace add Turki-Sh/Foreman
/plugin install foreman@alshuaibi

If your session answers that /plugin isn't available, it is a terminal-only dialog. Run the same two steps as shell commands, then restart the session.

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi

Update or remove

/plugin marketplace update alshuaibi
/plugin uninstall foreman@alshuaibi

Claude apps

Download foreman.skill and upload it in the skills settings. The modes and the four tools are inside it. Ask for a tool in plain words, such as "run the punch list on my site".

Every other agent

Cursor, Windsurf, Codex, Copilot, Gemini CLI, Cline, or anything that reads skills or rules. Copy one folder.

git clone https://github.com/Turki-Sh/Foreman.git
cp -r Foreman/plugins/foreman/skills/foreman ~/.agents/skills/

Cline, Continue, RooThe custom instructions or rules field

Paths move as tools change. The rule that always works: put SKILL.md where your tool reads standing instructions, and keep references/, toolbelt/ and assets/ next to it. AGENTS.md has the latest table.

A chat with no skills support

Paste SKILL.md into the conversation and say "run this on me". The steps, the modes and the gates all work from that one file. The references only deepen them.

Check it loaded

Say help me build my portfolio. The first reply is this card, then nothing. If it starts writing HTML, it did not load.

Questions

Does it run anything on my machine? No. Foreman is markdown and fill-in templates. It ships no scripts, no hooks, no MCP servers and no network calls, and its CI fails if any appear. Your agent uses its own tools, with your permission, as it always does.

Does it need the internet? No. Survey mode and the board get better when your agent can browse, and say so in one line when it cannot.

Which models does it work with? Any capable model your agent runs. The recorded runs on this site used Claude Sonnet.

What does it cost? Nothing. MIT licensed.
