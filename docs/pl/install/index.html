Foreman / Zainstaluj

Zainstaluj Foreman.

Jeden folder markdown. Nic się nie kompiluje i nic nie działa, więc instaluje się wszędzie tam, gdzie agent czyta pliki.

Claude Code

Uruchom obie linie w tej kolejności. Spowoduje to dodanie przewodnika i jego czterech narzędzi jako poleceń ukośnika.

/plugin marketplace add Turki-Sh/Foreman
/plugin install foreman@alshuaibi

Jeśli powierzchnia Claude Code nie obsługuje /plugin, uruchom te polecenia w swojej powłoce, a następnie rozpocznij nową sesję.

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi

Zaktualizuj lub usuń

Aktualizacja z powłoki:

claude plugin marketplace update alshuaibi
claude plugin update foreman@alshuaibi
/plugin uninstall foreman@alshuaibi

Używaj go ze swoją drużyną.

Opcjonalnie, dla projektów, w których Foreman jest częścią współdzielonego przepływu pracy.

Z katalogu projektu uruchom:

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi --scope project

To zapisuje Foreman w .claude/settings.json:

{
  "enabledPlugins": {
    "foreman@alshuaibi": true
  }
}

Zachowaj istniejące ustawienia i inne wpisy wtyczki. Przejrzyj różnicę, a następnie zatwierdź ten plik, aby współpracownicy otrzymali konfigurację. Każdy współpracownik nadal uruchamia te dwa polecenia raz na swoim komputerze. Zatwierdzenie ustawień nie powoduje pobrania dla nich wtyczki.

Do użytku osobistego zachowaj domyślną instalację zakresu użytkownika. Udostępnianie jest opcjonalne i działa również w prywatnych repozytoriach. Nie umieszczaj poświadczeń i nadpisań osobistych w udostępnionym pliku.

Aplikacje Claude

Pobierz foreman.skill i prześlij go w ustawieniach umiejętności. Znajdują się w nim tryby i cztery narzędzia. Poproś o narzędzie prostymi słowami, np. „uruchom Punch list w mojej witrynie”.

Każdy inny agent

Cursor, Windsurf, Codex, Copilot, Gemini CLI, Cline lub cokolwiek, co odczytuje umiejętności lub zasady. Skopiuj jeden folder.

git clone https://github.com/Turki-Sh/Foreman.git
cp -r Foreman/plugins/foreman/skills/foreman ~/.agents/skills/
NarzędzieGdzie trafia folder
Katalog umiejętności uniwersalnych~/.agents/skills/foreman/
Cursor~/.cursor/rules/lub .cursor/rules/ w projekcie
Codex~/.codex/skills/foreman/lub odwołaj się do niego AGENTS.md
GitHub Copilot.github/copilot-instructions.md, lub skieruj go na SKILL.md
Windsurf.windsurfruleslub katalog reguł obszaru roboczego
Gemini CLIGEMINI.mdlub katalog rozszerzeń
Cline, Continue, RooPole niestandardowych instrukcji lub reguł

Ścieżki poruszają się wraz ze zmianą narzędzi. Zasada, która zawsze działa: put SKILL.md gdzie Twoje narzędzie czyta stałe instrukcje i przechowuj je references/, toolbelt/ i assets/ obok. AGENTS.md ma najnowszą tabelę.

Czat bez wsparcia umiejętności

Wklej SKILL.md do rozmowy i powiedz „zleć mi to”. Kroki, tryby i bramki działają w oparciu o ten jeden plik. Odniesienia tylko je pogłębiają.

Pytania

Czy coś uruchamia się na moim komputerze? Nr Foreman to markdown i szablony wypełnień. Nie dostarcza żadnych skryptów, żadnych haków, żadnych serwerów MCP ani żadnych połączeń sieciowych, a jego CI kończy się niepowodzeniem, jeśli taki się pojawi. Twój agent jak zawsze korzysta z własnych narzędzi, za Twoją zgodą.

Czy potrzebuje internetu? Nie. Tryb Survey i narzędzie Board działają lepiej, gdy Twój agent może przeglądać Internet. Informują Cię w jednym wierszu, gdy przeglądanie jest niedostępne.

Z jakimi modelami to współpracuje? Dowolny model, który obsługuje Twój agent. Nagrane przebiegi na tej stronie wykorzystywały Claude Sonnet.

Ile to kosztuje? Nic. Licencja MIT.
