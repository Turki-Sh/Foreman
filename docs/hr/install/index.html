Foreman / Instalacija

Instalirajte Foreman.

Jedna mapa markdown. Ništa se ne kompajlira i ništa ne pokreće, tako da se instalira bilo gdje gdje agent čita datoteke.

Claude Code

Oba retka, ovim redom. Ovo dodaje priručnik i njegova četiri alata kao naredbe kose crte.

/plugin marketplace add Turki-Sh/Foreman
/plugin install foreman@alshuaibi

Ako vaša površina Claude Code ne podržava /plugin, pokrenite ove naredbe u svojoj ljusci, a zatim započnite novu sesiju.

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi

Ažurirajte ili uklonite

Ažuriranje iz vaše ljuske:

claude plugin marketplace update alshuaibi
claude plugin update foreman@alshuaibi
/plugin uninstall foreman@alshuaibi

Koristite ga sa svojim timom.

Izborno, za projekte u kojima je Foreman dio zajedničkog tijeka rada.

Iz direktorija projekta pokrenite:

claude plugin marketplace add Turki-Sh/Foreman
claude plugin install foreman@alshuaibi --scope project

Ovo bilježi Foreman u .claude/settings.json:

{
  "enabledPlugins": {
    "foreman@alshuaibi": true
  }
}

Zadrži postojeće postavke i druge unose dodataka. Pregledajte diff, zatim pošaljite ovu datoteku kako bi suradnici primili konfiguraciju. Svaki suradnik i dalje izvodi dvije naredbe jednom na svom računalu. Uvrštavanjem postavki ne preuzima se dodatak za njih.

Za osobnu upotrebu zadržite zadanu instalaciju korisničkog opsega. Dijeljenje nije obavezno i funkcionira iu privatnim spremištima. Držite vjerodajnice i osobna nadjačavanja izvan dijeljene datoteke.

Claude aplikacije

Preuzimanje foreman.skill i prenesite ga u postavke vještina. Načini rada i četiri alata su unutar njega. Zatražite alat jednostavnim riječima, poput "pokreni Punch list na mojoj stranici".

Svi ostali agenti

Cursor, Windsurf, Codex, Copilot, Gemini CLI, Cline ili bilo što što čita vještine ili pravila. Kopiraj jednu mapu.

git clone https://github.com/Turki-Sh/Foreman.git
cp -r Foreman/plugins/foreman/skills/foreman ~/.agents/skills/
AlatGdje ide mapa
Univerzalni imenik vještina~/.agents/skills/foreman/
Cursor~/.cursor/rules/, ili .cursor/rules/ u projektu
Codex~/.codex/skills/foreman/, ili ga uputite na AGENTS.md
GitHub Copilot.github/copilot-instructions.md, ili ga usmjerite na SKILL.md
Windsurf.windsurfrules, ili direktorij pravila radnog prostora
Gemini CLIGEMINI.mdili imenik proširenja
Cline, Continue, RooPolje prilagođenih uputa ili pravila

Staze se pomiču kako se alati mijenjaju. Pravilo koje uvijek djeluje: stavite SKILL.md gdje vaš alat čita važeće upute i čuvajte references/, toolbelt/ i assets/ pored njega. AGENTS.md ima najnoviju tablicu.

Chat bez podrške za vještine

Zalijepi SKILL.md u razgovor i reci "pokreni mi ovo". Koraci, modovi i vrata rade iz te jedne datoteke. Reference ih samo produbljuju.

Pitanja

Pokreće li nešto na mom stroju? Ne. Foreman je markdown i predlošci za popunjavanje. Ne isporučuje nikakve skripte, nema kuka, nema MCP poslužitelja i nema mrežnih poziva, a njegov CI ne radi ako se pojavi. Vaš agent koristi vlastite alate, uz vaše dopuštenje, kao i uvijek.

Treba li internet? Ne. Način rada Survey i Board postaju bolji kada vaš agent može pregledavati i recite to u jednom retku kada ne može.

S kojim modelima radi? Bilo koji sposobni model koji vaš agent pokreće. Snimljene vožnje na ovoj stranici koristile su Claude Sonnet.

Koliko košta? Ništa. MIT licenciran.
