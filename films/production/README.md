# Before the code

A 60-second Foreman product film by Turki Alshuaibi. This is an authored explanation of the playbook, not a recorded agent run. The examples use Turki Alshuaibi; the closing website reveal shows the actual Foreman website.

- Watch page: https://foreman.turkialshuaibi.com/films/
- English film: 1920 x 1080, 24 fps, H.264 High level 4.1, yuv420p, AAC, fast-start MP4.
- Captions: English plus all 32 Beta site languages, in WebVTT and SRT.
- Sound: original instrumental score and transitions generated by `score.py`; no voice, samples, stock music or paid media service.
- Fonts: locally bundled Inter under the included SIL Open Font License.
- Imagery: existing Foreman architectural asset and actual website screenshot. Reference-brand films are research only and are not included in the edit.

## Reproduce

Use Node 24, FFmpeg and Python with NumPy 2.3.1. In this directory:

```sh
npm ci
python score.py
ffmpeg -y -i public/score.wav -af loudnorm=I=-18:TP=-1.5:LRA=9 -ar 48000 -c:a aac -b:a 256k public/score.m4a
npm run dev -- --port=3233
npx remotion render src/index.ts BeforeTheCode out/master.mp4 --codec=h264 --crf=17 --pixel-format=yuv420p --x264-preset=slow --concurrency=4
ffmpeg -y -i out/master.mp4 -vf scale=in_range=full:out_range=tv,format=yuv420p -c:v libx264 -profile:v high -level:v 4.1 -preset slow -crf 17 -maxrate 16M -bufsize 32M -color_range tv -colorspace bt709 -color_primaries bt709 -color_trc bt709 -c:a copy -movflags +faststart ../../site/static/media/films/before-the-code-en-1080-v1.mp4
```

Keep Remotion packages at the same version. Zod is overridden to 4.6.6 to address GHSA-mrhx-c7xc-m3w5 in the default scaffold dependency tree.

The timeline lives in `src/Composition.tsx`. Caption cue timing and translations live in `../captions/`. The watch page is generated from `site/pages/films.html`; `scripts/film_assets.py` emits captions, player markup, the transcript and video sitemap. Translated screen copy remains subtitles for an English film, not alternate dubbed audio.

After changing the film, inspect the timeline and representative frames, update the poster and stills, run `node scripts/build_film_og.cjs`, rebuild the website, then run `python scripts/audit_films.py --media` from the repository root. Do not render the film during the ordinary site build or CI. The video is a versioned source asset.

For local seeking, use a byte-range-capable server such as `npx http-server@14.1.1 docs -p 3234 -c-1` from the repository root. Python's simple static server does not provide the same seeking behavior. Do not stop other preview servers.

The source and product versions are separate. This site-only film does not change the Foreman playbook version, which remains 3.0.1.
