# Foreman 404 redesign

## Direction and sources

Turki requested a major 404 redesign, preferring Sigma Software Design's ChainGPT composition: https://dribbble.com/shots/24367298-ChainGPT-Error-404-UI-Design . The actual animated reference was inspected in the browser. Visual observations: simple left-aligned recovery copy, large floating 3D robot on the right, scattered objects, framed dark canvas. Reconstructed as responsive HTML/CSS using Foreman's monochrome palette and existing navigation. No original source code or 3D model was recovered or claimed.

Additional galleries reviewed: https://dribbble.com/tags/404-page and https://www.404s.design/ . The specified ChainGPT shot remained the primary reference.

Turki explicitly approved generating the original Foreman character. Built-in image generation was used, no API fallback. The full-alpha WebP is site/static/media/foreman-lost.webp (189962 bytes), copied by the build to docs/media/foreman-lost.webp. It is not a new identity/logo or replacement for Turki's footer portrait.

## Generation prompt

Generate a premium 3D character cutout asset for the Foreman website 404 page. Genuine transparent background. One original friendly compact construction robot floating weightlessly, three-quarter view, head tilted curiously, arms out with open palms in a gentle lost shrug. Large soft rectangular charcoal face screen with two small simple white luminous eyes, substantial rounded rectangular head housing, WHITE architectural hard hat with raised center ridge, short graphite body, articulated black metal arms, little silver mechanical hands, compact boots. Precise polished industrial toy render, black ceramic, brushed aluminium, white helmet, subtle clear glass visor with reflections, tactile seams and fastening details. Monochrome black white silver only, absolutely no colorful accents. A few floating small geometric construction blocks and a rolled drafting sheet around the robot, restrained composition, no ground. Full body visible, centered, generous clear margins all sides, square image. Soft studio lighting, realistic ambient occlusion, elegant not cartoon flat vector, not humanoid face. No typography, no letters, no logo, no numbers, no UI. Render suitable both on white and black backgrounds, crisp silhouette with reflective edges. Original mascot design inspired by the idea of a lost construction foreman, not an existing branded robot.

## Verified locally

At 1440x1000 and 375x850, in both light and dark themes: genuine 404 response for an unknown path, noindex metadata, all five recovery destinations return 200, no axe WCAG A/AA violations, no page overflow, no script errors, and the artwork loads. Real desktop/mobile screenshots were inspected. The entrance is a single 1.2-second CSS transform/opacity animation and is omitted under prefers-reduced-motion. No extra JavaScript or external runtime is required. Local preview retained; not published.
